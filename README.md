# MaeDay: propertymanagementafterhoursansweringservice.com

Marketing site for **MaeDay**, after-hours answering for US property managers, by Antek Automation.

Not built yet. Claude Code builds it from `docs/BUILD_MAEDAY_SITE.md`, phase by phase.

- `docs/BUILD_MAEDAY_SITE.md`: the build brief (start here)
- `docs/RESEARCH.md`: Phase 1 research
- `docs/BUILD_PROMPT.md`: the one prompt to paste into Claude Code
- `docs/SETUP_CALL_PLAN.md`: SPIN plan for the 20-minute setup call
- `reference/design/`: design canvas files (brand board, Home, Pricing, Apartments, Compare)

Paste `docs/BUILD_PROMPT.md` into Claude Code to build v1.
